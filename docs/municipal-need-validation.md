# Municipal need validation

Status: AWAITING_MUNICIPAL_REVIEW

最終更新日: 2026-08-30

## 検証原則

実在自治体からの回答はまだない。仮説、候補、調査票を「検証済み」「採用済み」「SUPPORTED」と表示しない。実レビューを受けるまで全仮説は `AWAITING_MUNICIPAL_REVIEW` とする。

否定的回答は都合よく読み替えず、原文・回答者の役割・日時・対象バージョンを保持し、`PARTIALLY_SUPPORTED` または `CONTRADICTED` として記録する。自動分析だけで候補を `confirmed` にしない。

## 価値仮説

| ID | 仮説 | 状態 | 必要な証拠 |
|---|---|---|---|
| H1 | 交通・医療アクセスを追加確認すべき地域の選定には、複数データの収集・加工が必要である。 | AWAITING_MUNICIPAL_REVIEW | 現行手順、入力資料、担当者、所要期間、委託範囲 |
| H2 | 候補を500mだけでなく建物・道路・地形まで確認できることに価値がある。 | AWAITING_MUNICIPAL_REVIEW | PLATEAU詳細を使った/使わなかった場面と理由 |
| H3 | 順位や地図だけでなく、現地確認項目がまとまった資料が必要である。 | AWAITING_MUNICIPAL_REVIEW | 実際に使う調査票、必要欄、不要欄、持出方法 |
| H4 | 出典付き調査サマリーを庁内・交通事業者・コンサルとの協議に使える。 | AWAITING_MUNICIPAL_REVIEW | 利用会議、共有相手、必要な説明粒度、差戻し内容 |

## 自治体レビューで聞くこと

1. 現在、交通や医療へのアクセスを確認すべき地域はどのように選んでいますか。
2. 常団地前周辺、二尾周辺等は、実際に追加確認する価値がある候補に見えますか。
3. 候補地区一覧、地図、候補理由、PLATEAU詳細、不足データ、現地調査票、庁内共有資料のうち、業務に必要なのはどれですか。
4. この作業に現在どの程度の期間、担当者、外部委託が必要ですか。
5. この出力を誰との協議に使いますか。
6. 3種類の候補区分は実務上区別できますか。必要な別区分はありますか。
7. 調査票の状態、担当、期限、メモ、GPSのうち、持ち出せない情報はありますか。
8. 「政策推奨ではない」という境界は十分に伝わりますか。

## 採用判断で聞くこと

- この候補一覧を使いますか。
- この現地調査票を使いますか。
- どの会議・協議で使いますか。
- 何が足りませんか。
- 既存資料より便利ですか。
- 使わない場合、どの既存手順・資料で足りますか。

現行業務の時間・費用ベースラインは未収集である。状態は `BASELINE_NOT_COLLECTED` とし、削減時間や費用対効果を主張しない。

## レビュー記録の必須項目

- review ID
- 組織・部局（公開可否を別管理）
- 回答者の役割
- 実施日時
- 対象候補、選定ルール版、確認項目ルール版
- 質問と回答原文
- 観察事実と解釈の分離
- 回答の公開区分
- 仮説状態の変更理由
- 次の検証またはpivot

回答者名、連絡先、内部メモをpublic成果物へ含めない。

## 否定的回答とpivot条件

次のいずれかが確認された場合、無理に現行案を維持しない。

- 地域候補選定業務が存在しない
- 候補地域が実務上無意味
- 現地調査票が使われない
- 既存ツールで十分
- 必要な判断単位が異なる
- 交通・医療の組合せが業務に合わない

処理例:

| 回答 | 仮説状態 | 次の処理 |
|---|---|---|
| 既存施策で対応済み | CONTRADICTED | 対象候補を確認済みにせず、対象外理由を保持 |
| 選定業務自体が存在しない | CONTRADICTED | 対象業務を再定義するまで実装拡張を停止 |
| 一部の部署だけ使う | PARTIALLY_SUPPORTED | 部署・会議・権限境界を絞って再検証 |
| 情報は必要だが調査票は不要 | PARTIALLY_SUPPORTED | 出力形式をpivot候補として比較 |
| 地域事情と異なる | CONTRADICTED | 原データ・年次・不足情報・選定ルールを再確認 |

## 実施ゲート

Municipal Pilot Readyを名乗るための技術基盤と、自治体需要が実証されたことは別である。次の全条件を満たすまでStatusを変更しない。

1. 実在自治体の交通担当者による候補一覧レビュー
2. 少なくとも1件の調査票の実務適合性レビュー
3. 否定的回答を含む原記録の保存
4. 既存資料との比較
5. 利用会議または協議相手の特定
6. 採否と不足項目の明示
