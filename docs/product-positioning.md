# Product positioning: 現地調査候補をつくるツール

最終確認日: 2026-08-30

## 一文で表す価値

**500mの課題候補を、PLATEAUで現地調査対象まで具体化する。**

CITY GAPは、地域公共交通計画、デマンド交通、交通空白地域等を検討する自治体職員が、最初に現地確認すべき3〜5地域を選ぶための意思決定前処理ツールである。政策決定、危険判定、施策推奨、実施効果予測は行わない。

## 主利用者と成果物

主利用者は地域公共交通担当。高齢福祉、都市計画、公共施設、交通事業者連絡の各担当が共同利用者となる。

最終成果物は次の3点である。

1. 種類を分けた現地調査候補一覧
2. 不足情報から決定論的に生成し、人が編集できる現地調査票
3. 出典・限界・未確認状態を含む庁内共有用調査サマリー

## 公式ツールとの比較

比較は機能の優劣ではなく、対象業務と出力の違いを明示するために行う。

| 観点 | 都市構造評価ツール | 都市モニタリングシート / ハンドブック | CITY GAP |
|---|---|---|---|
| 主な対象業務 | 立地適正化計画の策定・更新、都市構造評価 | 都市の現況把握、都市間比較、定量評価 | 地域交通・医療アクセスの現地調査準備 |
| 主入力 | PLATEAU建物、各種オープンデータ、自治体独自施設・区域案 | 都市計画現況調査、基幹統計等 | 国勢調査500m、交通・医療施設、PLATEAU、任意の自治体確認情報 |
| 主な分析単位 | 建物、圏域、誘導区域、自治体・隣接自治体 | 自治体、都市類型、指標 | 500m候補→建物群・道路・地形→現地確認項目 |
| 建物人口配分 | 延べ床面積を用いた建物単位配分を実装 | 対象外 | 既存高度分析では推計を保持するが、公開候補の差別化には使わない |
| 指標算出・可視化 | 多様な指標の算出、地図・グラフ表示 | 約400指標、個票、レーダーチャート | 既存実データを候補理由として最大3値に絞る |
| 自治体データ取込 | 独自施設、区域案等に対応 | Excel等の提供資料を利用 | 実レビュー後の確認情報を内部記録として扱う |
| 複数案比較 | 誘導区域変更前後や複数区域案を比較 | 自治体・都市類型間を比較 | 高度分析にはシナリオ比較を保持するが、公開フローの主目的ではない |
| 主出力 | 都市構造指標、地図、グラフ、CSV等 | 全体表、自治体個票、比較図 | 候補一覧、現地調査票、庁内調査サマリー |
| 不足データ→確認項目 | 本比較で確認した公式説明上の主出力ではない | 対象外 | ルール版付きで決定論的に生成 |
| 現地向け編集・通信なし利用・印刷 | 本比較で確認した公式説明上の主出力ではない | 個票は印刷可能 | 担当・期限・状態・メモ・GPSを端末内に保存し印刷 |
| 自治体レビュー状態 | 有用性検証を実施済み | 制度・評価手法として提供 | 候補ごとに未確認を保持し、自動で確認済みにしない |
| 観察・証拠の系譜 | 分析データ・算式を管理 | 指標定義・出典を管理 | data gap→check、候補→調査票、public/internal境界を保持 |
| 判断との境界 | 計画検討・都市構造評価を支援 | 客観的・定量的な把握を支援 | 調査順の検討材料。政策判断を代替しない |

## 公式ツールが既に持つため、独自性として主張しないこと

- PLATEAUとオープンデータの統合
- 都市構造指標の算出と地図・グラフ可視化
- 建物への人口配分
- 自治体独自データの取込
- 誘導区域案の前後・複数案比較
- 隣接自治体を含む広域表示
- CSV等の分析結果出力

## CITY GAPが検証する差分

1. 500mのFindingを「分析上の候補」「詳細調査例」「データ確認候補」に分けられるか。
2. PLATEAU収録の有無を隠さず、建物・道路・地形へ確認対象を具体化できるか。
3. GTFS、公式歩行ネットワーク、施設利用条件、地域内サービス等の不足を、理由付き確認項目へ変換できるか。
4. 調査票を通信なし・モバイル・印刷で扱い、担当者が編集できるか。
5. 否定的な自治体回答を含め、未確認→レビュー→判断の証拠を保持できるか。
