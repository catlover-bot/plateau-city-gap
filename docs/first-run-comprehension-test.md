# First-run comprehension test

Status: AWAITING_HUMAN_TEST

## 目的

初めてCITY GAPを開く人が、予備知識なしで「地域候補を見つける → 都市構造まで掘り下げる → 仮説を比較する → 根拠を確かめる」を一つの調査として理解できるかを確かめる。操作成功だけでなく、候補は危険度を示さず、施策比較も実施後の効果予測ではないと説明できるかを確認する。

## 参加者と環境

- 実在する参加者を最低3名招く。例: 地図の専門知識がない人、自治体業務を知る人、GISまたは都市分析を知る人。
- 少なくとも1名は幅390px程度のモバイル、残りはデスクトップで行う。
- 各セッションは新しいブラウザーセッションとPublic ShowcaseのベースURLから始める。
- 同意を得てから観察し、参加者IDだけを記録する。氏名や不要な個人情報は残さない。

## 進行スクリプト

進行者は画面の言葉を先回りして説明せず、次の順に観察する。

1. Landingを見せ、「これは何を見つけるサービスだと思いますか」と聞く。主要CTAを自力で見つけ、1回の操作で調査を始められるかを記録する。
2. Step 1「どこが気になる？」で、何を選んだか、舞鶴市の何件から見ているかを聞く。
3. Step 2「なぜ候補になった？」で、根拠を最大3つ、参加者自身の言葉で説明してもらう。候補が危険度や行政の優先順位を意味するかも聞く。
4. Step 3「街のどこで起きている？」まで進み、500mメッシュから建物・道路・地形へ確認範囲が変わったことを説明してもらう。ここで再読み込みし、同じStepと選択が戻るか確認する。
5. Step 4「施策を変えるとどうなる？」で、現在値・仮想条件・差分を説明してもらう。その差分が実施後の効果予測かどうかも聞く。
6. Step 5「その数字の根拠は？」で、最低2つの出典と年次を見つけられるか確認する。「詳しい出典を見る」へ進み、元の調査に戻れるかも観察する。
7. 完了後に「詳しい分析を開く」と「最初から見る」をそれぞれ試し、行き止まりなく遷移できるか確認する。
8. 最後に「CITY GAPが示したこと」と「示していないこと」を1つずつ聞く。

## 進行者用の確認基準

この節は参加者に見せず、回答の意味が合っているかを判定するために使う。言葉の一致は求めない。

- Step 1: 舞鶴市の495メッシュから実在する `533513314` 常団地前周辺を選んだと理解する。順位に言及する場合は総合23位が正しい。
- Step 2: 高齢者200人、公共交通まで563m、医療まで1.45kmの3つを候補理由として捉え、危険度や行政の優先順位ではないと理解する。
- Step 3: 500mメッシュから、実在するPLATEAU建物296棟、道路、実DEMへ掘り下げていると理解する。3D読み込み中の2D建物形状や断面は代替表示であり、未完了の3Dを完成と受け取らない。
- Step 4: 現在の563m、仮想支援地点条件の30m、差分の−533mを区別し、実施後の効果予測ではないと理解する。
- Step 5: 国勢調査2020、国土数値情報のバス停2022と医療施設2020、PLATEAU舞鶴市関連データの駅2025と3D都市モデル2025、CITY GAPの計算方法のうち、2つ以上を画面から見つける。

## 記録と判定

各参加者について、デバイス、開始までの操作回数、5ステップ到達、再読み込み後の復帰、行き止まり、根拠・PLATEAUの役割・仮説の限界に関する回答を観察事実として記録する。迷いが起きた場所は、発話と画面の質問を紐づける。

合格基準は次の全項目とする。

- 3名以上の実参加者が、進行者の操作代行なしで5ステップへ到達する。
- 全参加者が主要CTAから1回の操作でStep 1を開く。
- 少なくとも3名中2名が、候補の3要素、PLATEAUで掘り下げる対象、仮想条件の限界を自身の言葉で正しく説明する。
- モバイル参加者がCTAを見失わず、地図操作とシートのスクロールを独立して行える。
- 再読み込み、詳細出典、詳細分析、最初から見るのいずれでも行き止まりがない。

未実施のため、現時点で結果、達成率、参加者の発話は記録しない。実セッション後にのみ、観察した事実と改善必要点を追記し、Statusを更新する。
